# VerdeVivo Ecommerce

Aplicação full stack de ecommerce para eletrônicos (celulares, tablets e computadores) com design naturalista e paleta verde clara.

## Requisitos

- Node.js 18+

## Como rodar

```bash
npm install
npm run start
```

Acesse `http://localhost:3000`.

## Funcionalidades

- Catálogo com busca e filtros por categoria
- Destaques, carrinho e checkout simulado
- API em Express com rotas para produtos, categorias e checkout
